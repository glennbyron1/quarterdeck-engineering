# Security and disclosure

This repository contains a sanitized portfolio case study, not deployable
Quarterdeck software.

Please do not open a public issue containing credentials, private lab details,
personal information or vulnerability data from systems you do not own. If you
believe this repository accidentally exposes sensitive information, contact the
repository owner privately through the contact method on the owner's GitHub
profile.

The architecture and controls described here are research artifacts. They are
not a supported security product, certification or authorization.
